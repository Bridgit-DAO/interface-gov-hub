# 📝 Hypothesis Annotations - User Guide

## Quick Start (30 seconds)

### Step 1: Create Free Hypothesis Account
1. Go to **https://hypothes.is/signup**
2. Enter your **email** and create a **password**
3. Click **"Sign up"** - that's it!

### Step 2: Enable Annotations on Documents
1. Go to any document: **https://dev.rfc.themetalayer.org/doc/draft/vwbegvz1/**
2. Look for **"Actions"** card in the right sidebar
3. Click **"Enable Annotations"** button
4. Page reloads with Hypothesis enabled

### Step 3: Start Annotating
1. **Select any text** in the document
2. Click the **"Annotate"** button that appears
3. **Type your annotation**
4. Click **"Post to Public"**

## ✨ What You Can Do

### 📝 **Create Annotations**
- Select text → Add detailed comments
- Share insights, questions, corrections
- Reference other documents or sources

### 🖍️ **Create Highlights**  
- Select text → Click highlighter icon
- Mark important sections without commenting
- Visual emphasis for key points

### 💬 **Reply to Annotations**
- Click on any existing annotation
- Add your thoughts to the conversation
- Build discussions around specific text

### 🔍 **Filter & Search**
- Use Hypothesis sidebar to filter annotations
- Search by keyword or author
- View only your annotations

### 👥 **Join Groups** (Optional)
- Create private annotation groups
- Collaborate with specific teams
- Control who sees your annotations

## 🎯 Document-Specific Features

### **Meta-Layer Drafts**
- Each draft gets its own annotation space
- Annotations tagged with `draft:document-name`
- Easy to find annotations for specific documents

### **Revision Tracking**
- Different draft revisions have separate annotations
- Historical context preserved
- Clear version-specific discussions

## 🔧 User Settings

### **Annotation Visibility**
- **Public**: Everyone can see (default)
- **Private**: Only you can see
- **Group**: Only group members can see

### **Notification Preferences**
- Get notified of replies to your annotations
- Control email notification frequency
- Manage via Hypothesis account settings

## 💡 Best Practices

### **For Reviewers**
- ✅ Quote specific text when making suggestions

## 🚀 Advanced Features

### **Keyboard Shortcuts**
- **Ctrl+Shift+A**: Toggle Hypothesis sidebar
- **Ctrl+Shift+H**: Create highlight
- **Escape**: Close annotation editor

### **Browser Extensions**
- Install Hypothesis browser extension
- Annotate any webpage, not just Meta-Layer docs
- Sync annotations across all sites

### **API Access**
- Developers can access annotations via Hypothesis API
- Build custom tools and integrations
- Export annotation data

## 🛠️ Troubleshooting

### **Annotations Not Loading**
1. Check if you clicked "Enable Annotations"
2. Refresh the page (Ctrl+F5)
3. Check browser console for errors
4. Try different browser

### **Can't Create Annotations**
1. Make sure you're logged into Hypothesis
2. Check if you have a Hypothesis account
3. Try logging out and back in
4. Clear browser cache

### **Annotations Not Saving**
1. Check internet connection
2. Try shorter annotation text
3. Refresh page and try again
4. Contact support if persistent
